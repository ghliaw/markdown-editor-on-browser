# 墨流 Markdown 編輯器

免安裝、可直接在現代瀏覽器中執行的 Markdown 編輯器。

## 使用方式

直接以 Chrome、Firefox 或 Edge 開啟 `dist/index.html` 即可。若瀏覽器限制本機檔案功能，也可在專案目錄啟動任一靜態網頁伺服器。

## 功能

- 編輯、顯示、左右窗格三種模式
- Markdown 即時預覽與常用格式工具列
- 多層項目／編號／待辦清單，可在各層自由混搭
- 新增、開啟、儲存／另存 Markdown 文件
- `Ctrl+B`、`Ctrl+I`、`Ctrl+K`、`Ctrl+S` 等快捷鍵
- 自動保存瀏覽器內的工作草稿
- 響應式版面，可在窄螢幕上下分割

## 多層清單

在清單項目上按 `Tab` 可增加一層縮排，按 `Shift+Tab` 可減少一層；也可以選取多行後使用工具列的項目、編號或待辦清單按鈕。不同層級可以自由混用：

```markdown
- 第一層項目
  1. 第二層編號
    - 第三層項目
  2. 另一個第二層編號
- 回到第一層
```

## AI 使用說明

本專案在開發過程中使用 OpenAI Codex 作為 AI 協作工具，主要用於：

- 將需求整理為介面與功能規格
- 協助撰寫 HTML、CSS 與 JavaScript 程式碼
- 建議響應式版面、無障礙標示與瀏覽器相容性處理方式
- 協助測試三種顯示模式、Markdown 格式工具及檔案操作
- 撰寫與整理專案說明文件

所有 AI 產生的內容仍應由專案維護者檢查、測試並確認後使用。此編輯器執行時不會連接 AI 服務，也不會將使用者輸入的 Markdown 內容傳送給 AI；文件內容只會保留在瀏覽器或使用者主動選擇的本機檔案中。
